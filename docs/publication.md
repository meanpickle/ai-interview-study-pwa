# 公开发布边界

公开仓库包含：原创应用源码、公共仓库链接与文件名索引、原始来源下载脚本、自动化检查、PWA 图标、带各自许可证的阅读组件。

公开仓库不包含：原始第三方资料全文与图片镜像、先前 1.3 GB Windows 离线资料库、用户的学习记录、签到和笔记、私人正文包、浏览器数据库、访问令牌或本机凭据。

`tools/check-public.mjs` 校验发布目录白名单、凭据特征、异常大文件和禁止发布的资料包/记录文件。发布工具读取的是这个独立项目目录，不会递归提交其上级工作区或以前的 release 文件夹。

`web/catalog.json` 的文档项只有 `id`、`path`、`kind` 和 `title` 四个字段；标题由文件名生成，不包含抽取的答案。正文只会在用户主动打开或下载时由设备访问原始 GitHub。

原仓库可访问不等同于统一再分发许可。正文不随应用发布，是为了保留原始来源与许可边界；下载后的复用或再分发仍需查看原作者说明。应用 MIT 许可不覆盖这些外部资料。

GitHub Pages 仅部署 `web/`。持续集成不运行原始资料仓库里的脚本，不下载题库全文，也不会上传私人正文包。
