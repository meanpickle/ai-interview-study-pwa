# 迁移与离线

## 两类导入文件

| 类型 | 入口 | 包含什么 | 是否改变阅读记录 |
| --- | --- | --- | --- |
| Windows / PWA v1 记录 JSON | 备份与设置 → 导入记录 | 阅读比例、章节、笔记、已学状态、签到、计时与复盘 | 替换当前记录，预先保留旧记录 |
| `.study-pack.json` 正文包 | 离线 → 导入离线资料包 | 资料标识、原始正文、来源信息 | 否 |

可先导入记录再导入正文，也可反过来。正文只在用户设备保存。

## 断网后能做什么

在首次联网打开并完成离线页面准备后，应用界面、字体、公式、笔记和签到不需要服务器。已缓存或已导入的正文可离线打开；未下载的文章只显示索引，需要联网或导入资料包。

全文搜索只覆盖本设备已缓存的正文，不会为了搜索而偷偷批量下载全部资料。图片在在线阅读时按需缓存，单图最多缓存 2 MB、最多保留 80 张；超出限制和跨域不允许缓存的图片仍需要联网。

## 记录可靠性

学习记录与正文使用 IndexedDB 的不同对象仓库。学习操作在读写事务中更新，避免计时保存覆盖刚写的笔记。资料包先完整验证，再通过单个事务导入；如果失败，原缓存不被半途覆盖。

页面退出时暂存的阅读动作通过本机日志恢复；恢复动作带事务内去重标记，避免重复累计同一份退出计时。它可以减少突然关闭带来的损失，但不能代替主动备份或浏览器的持久存储能力。

导入记录只支持当前 v1 格式；不接受空对象、无效日期、非法阅读比例或异常字段。导入前的副本可在设置中恢复。应用不替用户合并多台设备的笔记，没有自动云同步。

## 安卓安装与浏览器边界

安装入口取决于浏览器与使用状态。使用支持 PWA 的新版 Android Chrome / Edge 打开 HTTPS 地址，应用设置中的安装按钮会在浏览器提供安装事件时调用它；否则提示从浏览器菜单安装。

参考：[MDN：安装 PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[MDN：离线与后台运行](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation)。
